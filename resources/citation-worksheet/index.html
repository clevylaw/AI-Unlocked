Citation checking worksheet

A printable worksheet for checking every authority in a document, whether or not AI helped write it.

· Report a correction (opens GitHub in a new tab)

AI for Legal Work · https://clevylaw.github.io/AI-Unlocked/resources/citation-worksheet/ · Content last reviewed November 2026

Use one row for each authority. Courts have sanctioned lawyers for citing cases that did not exist. Asking an AI tool whether a case is real proves nothing.

The five checks

  1. Find it in a trusted legal database or on an official court or government website.
  2. Read it. Read the passage you rely on. A summary is not enough.
  3. Good law. Run it through a citator. Confirm statutes and rules are current.
  4. Details. Match every quote, pin cite, court and date to the original.
  5. Fit. Confirm it is binding or persuasive in this court.
