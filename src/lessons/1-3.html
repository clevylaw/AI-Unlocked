Artificial intelligence

This is the big idea. Computers do jobs that seem to need human thinking.

Machine learning

This is the main way people build AI today. The computer learns patterns from examples, as you saw in the last lesson. When people say "AI" today, they usually mean machine learning.

Deep learning

Deep learning is a strong kind of machine learning. Its design was loosely inspired by the brain. It uses neural networks, which are many layers of simple math stacked on top of each other. These layers can find complicated patterns. Deep learning runs voice assistants, photo search and chatbots.

Generative AI

Generative AI is deep learning that makes new things. It can write text, draw pictures, make music, write computer code and create video. Older AI mostly sorted or labeled things. The next module is all about generative AI.

Narrow AI and general AI

Every AI you can use today is "narrow." It is good at the jobs it was trained for and nothing else. Some companies are trying to build "general AI," also called AGI. That would be a machine that can do any thinking task as well as a person. Experts disagree about how close anyone is to building it.
