More than chat

A chatbot answers you. An AI agent takes action. You give it a goal. It breaks the goal into steps and uses tools, such as a web browser. It checks its work and keeps going until the task is done.

Example

"Find three flights to Rome in May that cost less than $600. Compare them in a table. Then write an email to my partner about the best one." An agent can do all of that and only ask you to make the decisions.

Agents you can use today

  • Agents that use a computer. Assistants from OpenAI, Anthropic and Google can work a web browser. They click, type and fill in forms to finish a task.
  • Coding agents. Tools such as Claude Code, OpenAI Codex, GitHub Copilot and Cursor can build and fix software from a request in plain English.
  • Research agents. The "deep research" modes in ChatGPT, Gemini and Claude spend several minutes reading dozens of sources. Then they write a report with links to those sources.

Stay in charge

An agent that can send emails, spend money or delete files needs limits. Good agents ask you before they do anything important. Give an agent only the access it needs for the task, and check what it did.
