An API call

Apps talk to models through an API, which is a set of rules that lets one program ask another program for something. Your code sends instructions and messages, and it gets a reply back. A typical request looks like this. The details differ from company to company.

{
  "model": "a-model-name",
  "system": "Answer only from the firm policy provided. Quote the section you relied on. If the policy does not cover it, say so.",
  "messages": [
    { "role": "user", "content": "Can I use my personal laptop for client work?" }
  ],
  "max_tokens": 300
}

The system prompt sets the model's role, tone and rules for the whole conversation. Results get much more reliable when you include one or two worked examples and ask for a fixed format.

Retrieval-augmented generation (RAG)

A model never saw your firm's documents in training. RAG lets it answer from them anyway. Most legal research tools work this way, using a database of cases and statutes. It works in three steps.

  1. Split the documents into short chunks. Turn each chunk into an embedding, which is a list of numbers that captures its meaning.
  2. When a question comes in, turn it into an embedding too. Then find the chunks whose meaning is closest.
  3. Put those chunks into the prompt. Ask the model to answer only from them and to say which chunks it used.

If the search step finds the wrong passages, the answer will be wrong too, even with real citations attached. That is one reason legal research tools still make mistakes.

Prompting, RAG or fine-tuning

Start with a good prompt. Add RAG when answers depend on your own documents or on law that changes. Think about fine-tuning, which means extra training on your own examples, only when you need the same style at a large scale and a prompt cannot get you there.

Two safety basics

Keep API keys on a server, never in a web page users can look inside. And do not trust incoming documents. Text hidden in a document, such as a file produced by the other side, can try to give the model orders. This is called prompt injection.
