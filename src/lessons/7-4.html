Tools

You describe tools to the model. Each description gives the tool's name, what it does and what information it needs. Legal examples are search_case_law, open_matter_file and calculate_deadline. When a tool would help, the model replies with a request to use it. Your code runs the tool and sends the result back. Then the model carries on.

The agent loop

  1. Goal
  2. Plan the next step
  3. Use a tool
  4. Read the result
  5. Repeat or finish

An agent is this loop running until the goal is met. MCP, short for Model Context Protocol, is an open standard that Anthropic introduced in 2024. Many companies now support it. It lets AI apps connect to tools and information in one standard way.

Safety limits

  • Give each agent only the access it needs. Respect ethical walls, the barriers that keep information about one matter away from people working on another.
  • Have a person approve anything that is filed, sent to a client or paid.
  • Keep a record of every tool the agent uses, and set limits on time and spending.

Testing

Before you rely on an AI system, build a set of test cases, called an evaluation set. Each test case is a real task plus a description of a good answer. For legal research, that might be 50 questions where you already know the right cases. Check the answers automatically where you can, and have lawyers check a sample by hand. Run the tests again every time the tool, the model or your prompts change. Small changes often have surprising effects.

Ask vendors for this

Ask any legal AI vendor how they test accuracy, on what kinds of questions, and how often their citations are wrong. Then run a small test of your own on your kind of work.
