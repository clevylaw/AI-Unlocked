Types of AI

You will hear names like machine learning, deep learning and generative AI. They fit inside each other like boxes.

One picture explains it

These names do not compete with each other. Each one sits inside the one before it.

Artificial intelligence

This is the big idea. Computers do jobs that seem to need human thinking.

Machine learning

This is the main way people build AI today. The computer learns patterns from examples, as you saw in the last lesson. Technology-assisted review in e-discovery is machine learning. When people say "AI" today, they usually mean machine learning.

Deep learning

Deep learning is a strong kind of machine learning. Its design was loosely inspired by the brain. It uses neural networks, which are many layers of simple math stacked on top of each other. These layers can find complicated patterns. Deep learning runs speech-to-text transcription, translation and chatbots.

Generative AI

Generative AI is deep learning that makes new things. It can draft a letter, sum up a deposition, translate a contract or write computer code. Older AI mostly sorted or labeled things. This difference matters in law. A tool that sorts documents can miss some. A tool that writes can invent things that are not true.

Narrow AI and general AI

Every AI you can use today is "narrow." It is good at the jobs it was trained for and nothing else. Some companies are trying to build "general AI," also called AGI. That would be a machine that can do any thinking task as well as a person. Experts disagree about how close anyone is to building it.

For technical readers (optional)

A neural network is a stack of layers. Each layer multiplies its inputs by a grid of numbers and then applies a simple bend, called a non-linear function. "Deep" means there are many layers. Generative models learn how likely different outputs are and then pick from those chances. Language models do this one word piece at a time. Image models called diffusion models learn to undo added noise. Older e-discovery tools often used simpler machine learning methods, such as logistic regression or support vector machines, which can work well with less data.
